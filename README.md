    ### 🌟 Featured Projects & Open Source
    
    #### ⚙️ [DataEngine — Automated Data Preprocessing & Profiling Toolkit](https://github.com/jaynarayan-
  yadav/DataEngine)
    *A scikit-learn compliant data diagnosis and preprocessing engine built for production ML pipelines.*
    - **No Data Leakage:** Follows strict `fit`/`transform` semantics so statistics learned on training
  splits apply consistently during inference.
    - **Interactive & Autonomous Modes:** Features pre-cleaning diagnosis cards, CLI tooling, and granular
  step chaining via `df.pipe`.
    - **Pipeline Serialization:** Full support for `save()`/`load()` and integration inside `sklearn.
  pipeline.Pipeline`.
    - *Tech:* Python, pandas, NumPy, scikit-learn, pytest (67+ unit tests).
    
    #### 🧪 [scipy/scipy — Array API & Signal Processing Fixes](https://github.com/scipy/scipy/pull/26408)
    *Contributed to SciPy's digital signal filtering subsystem (`scipy.signal.sosfilt`).*
    - Resolved unhandled zero-length edge cases across custom filter sections while maintaining strict
  Array API standard compliance and device compatibility (`xp`).
